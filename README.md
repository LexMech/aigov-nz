# AIGov Maturity

AI Governance Maturity Assessment platform for New Zealand organisations.

Live site: [aigov.co.nz](https://aigov.co.nz)

## About

Organisations complete a questionnaire and receive a maturity score across six AI governance domains:

- Governance & Accountability
- Data Security & Privacy
- Bias, Fairness & Equity
- Reliability & Accuracy
- Risk Assessment & Mapping
- Transparency & Explainability

Results are scored across five maturity levels: Initial → Developing → Defined → Managed → Optimising.

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS 3.4.1 + shadcn/ui
- GitHub Pages (custom domain)
